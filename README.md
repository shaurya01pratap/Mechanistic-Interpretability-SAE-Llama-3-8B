# SAE Mechanistic Interpretability Pipeline

Automated feature interpretation and activation extraction using Sparse Autoencoders (SAEs) and the Gemini API.

> **Note:** This project requires significant GPU RAM for SAE extraction. Running on Kaggle is strongly recommended.

---

## Pipeline Overview

Two notebooks run in sequence:

| Step | Notebook | Input | Output |
|------|----------|-------|--------|
| 1 | `Linear Probing and SAE Feature Extraction.ipynb` | `principledata` | `Raw_Activations_*.csv` |
| 2 | `Autointerpretability.ipynb` | `principledata` + `saellama3` | JSON context dicts + CSV scores |

**Datasets:**
- **`principledata`** — Original prompts and ground-truth answers (`Principle1.csv`, etc.)
- **`saellama3`** — Pre-computed SAE activation matrices (`Raw_Activations_*_Layer_*.csv`)

## Running on Kaggle

[![Kaggle](https://kaggle.com/static/images/open-in-kaggle.svg)](https://www.kaggle.com/your-username/your-notebook-name)

**1. Add secrets** via *Add-ons → Secrets*:
- `GEMINI_API_KEY` — your [Google AI Studio](https://aistudio.google.com) key
- `HF_TOKEN` — your Hugging Face read token

**2. Attach datasets** to your notebook environment:
- For Notebook 01: attach `principledata`
- For Notebook 02: attach `principledata` and `saellama3`

Filesystem routing is handled automatically. Notebook 01 writes activations to `/kaggle/working/`; Notebook 02 reads inputs from `/kaggle/input/`.

## Running Locally

### 1. Install dependencies

```bash
git clone <repo-url>
cd <repo-name>
cp .env.example .env          # fill in your keys
pip install -r requirements.txt
```

### 2. Download datasets

Requires the [Kaggle API](https://github.com/Kaggle/kaggle-api) and a configured `kaggle.json`.

```bash
# Principle data (required for both notebooks)
kaggle datasets download -d shaurya01pratap/principledata -p data/principledata --unzip

# Pre-computed SAE activations (skip if running Notebook 01 yourself)
kaggle datasets download -d shaurya01pratap/saellama3 -p data/saellama3 --unzip
```

### 3. Expected directory structure

```
project-root/
├── data/
│   ├── principledata/
│   │   └── New Clean Data/
│   │       ├── Principle1.csv
│   │       └── ...
│   └── saellama3/           # pre-computed activations (or generated by Notebook 01)
│       └── Raw_Activations_*.csv
├── notebooks/
│   ├── Linear Probing and SAE Feature Extraction.ipynb
│   └── Autointerpretability.ipynb
├── output/                  # results written here
├── .env
└── README.md
```

### 4. Run the pipeline

**Full pipeline:**
1. Run `Linear Probing and SAE Feature Extraction.ipynb` — outputs `Raw_Activations_*.csv` to `output/`
2. Move those files into `data/saellama3/`
3. Run `Autointerpretability.ipynb`

**Skip Step 1** (if your GPU cannot handle 4-bit Llama-3 extraction):  
Download the pre-computed `saellama3` dataset (see Step 2 above) and run Notebook 02 directly.
